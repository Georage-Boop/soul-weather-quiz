# 你的灵魂天气 · Soul Weather

每个人心里都有一片天空。回答 6 道题，看看你的灵魂今天是晴空万里，还是正在下雷阵雨。

## 怎么玩

双击打开 `index.html` 就能玩，不用装任何东西，浏览器打开即玩。

也可以开 GitHub Pages 在线玩：仓库 Settings → Pages → Branch 选 `main`，保存后等一会儿就能用链接访问。

## 玩法说明

- 6 道选择题，每道题的每个选项对应一种天气类型
- 4 种结果：
  - ☀️ 晴空万里 —— 能量满满的小太阳
  - ⛅ 多云转晴 —— 慢热，但熟了比谁都暖
  - 🌧️ 绵绵细雨 —— 细腻温柔，共情力拉满
  - ⛈️ 雷阵雨 —— 情绪来得快去得也快，爆发力极强
- 测完会给出今日「宜 / 忌」，还能再测一次

## 技术

纯 HTML + CSS + JavaScript 单文件实现，零依赖、零构建。计分逻辑很简单：每个选项给对应天气加 1 分，得分最高的天气就是结果（并列时取先出现的）。
